# Удобные заметки 3.0

Заметки для Android и ПК (Windows): напоминания, будильник, гибкое форматирование, таблицы и плагины.

- 🌐 **Сайт со скачиванием:** https://legoman-1337.github.io/notes/
- 📥 **Релизы (APK + установщик для Windows):** https://github.com/Legoman-1337/notes/releases

## Что в версии 3.0

- Магазин плагинов с вкладками: «Рекомендуемые» (со стрелочкой — список можно скрыть), «Дополнительно» (100+ прикольных плагинов) и «Пакеты дополнительных плагинов» (готовые наборы одной кнопкой)
- Рекомендуемые плагины: «Журнал и Табель», «Привычки», «Долг», «Расписание», «Дни рождения», «Покупки», «Коммуналка»
- Облачная синхронизация заметок и данных плагинов
- Новые плавные анимации переходов
- Отдельная версия для ПК (Windows) с теми же возможностями

## Открытый код

В репозитории в открытом доступе лежат основные классы приложения (`*.kt`) и манифест (`AndroidManifest.xml`) — та часть, которая показывает устройство приложения. Сборочные артефакты, ключи и служебный мусор сюда не выкладываются, поэтому готовые сборки скачиваются из раздела [Releases](https://github.com/Legoman-1337/notes/releases), а отсюда можно просто посмотреть, как всё устроено.

Что здесь лежит:

| Файл | За что отвечает |
|---|---|
| `MainActivity.kt` | интерфейс и логика экранов |
| `AppwriteService.kt` | вход и подключение к облаку |
| `AppwriteCloudSync.kt` | облачная синхронизация заметок |
| `NoteReminder.kt` | напоминания и будильник |
| `RichText.kt` | форматирование текста в заметках |
| `StartupAnimation.kt` | анимация запуска |
| `WelcomeSetupFlow.kt` | первое включение приложения |
| `AndroidManifest.xml` | манифест Android-приложения |
| `index.html` | сайт проекта |
