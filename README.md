# Удобные заметки 3.5.5

Бесплатное офлайн-приложение для личных заметок на Android. Заметки хранятся **только на устройстве** — аккаунты, регистрация и серверы не нужны. Внутри есть магазин плагинов (мини-приложения для бытовых задач) и собственный загрузчик обновлений.

- Сайт с загрузками: https://legoman-1337.github.io/notes/
- Готовые сборки: https://github.com/Legoman-1337/notes/releases (APK для Android + portable-архив для Windows)
- Обновления: приложение само проверяет GitHub Releases и предлагает установить новую версию

## Возможности

- Заметки по разделам: «Важное», «Работа», «Бассейн», «Подготовка к занятию», «Подготовка к индивидуальному занятию» (разделы можно менять под себя)
- Поиск, сортировка по дате, редактирование и удаление
- **Магазин плагинов** — вкладки «Рекомендуемые» / «Дополнительно» / «Пакеты» / «Мои»: 44 дополнительных плагина (долги, дни рождения, коммуналка, списки покупок и т.д.) и тематические пакеты — вечеринка, дом, деньги, здоровье, настроение, учёба, поездки. Плагины работают без интернета
- **Напоминания** — уведомления по времени, работают после перезагрузки телефона
- Приветственная настройка при первом запуске, анимации переходов, собственные диалоги вместо системных

## Структура исходного кода

| Путь | Что это |
|---|---|
| `app/` | Android-приложение (Kotlin + Jetpack Compose) |
| `app/build.gradle` | Версия приложения (3.5, build 15), зависимости, конфиг подписи |
| `app/src/main/java/ru/momnotes/app/` | Весь код приложения — пояснение классов ниже |
| `app/src/main/assets/plugins/` | Встроенные плагины |
| `app/src/main/assets/plugins_extra/` | 44 дополнительных плагина магазина (генерируются скриптом) |
| `app/src/main/res/` | Ресурсы Android: иконки, темы, строки |
| `plugin-registry/` | Python-генератор дополнительных плагинов — пишет их в `assets/plugins_extra` (`plugin-registry/extra/generate.py`) |
| `docs/` | Политика конфиденциальности (`privacy.html`) и заметки о релизах |
| `gradle/`, `gradlew`, `gradlew.bat` | Gradle wrapper — проект собирается без установленного Gradle |
| `index.html` | Сайт-страница скачивания (GitHub Pages) |

ПК-версия (Windows) распространяется готовым portable-архивом в Releases; её исходники в репозиторий не входят.

## Сборка из исходников

1. Android Studio (AGP 8.7.3) + JDK 17 + Android SDK Platform 35.
2. **Open** → папка репозитория (где лежит `settings.gradle`), дождаться Gradle Sync.
3. `Build → Build APK(s)` или в терминале: `gradlew.bat assembleDebug`.
4. Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Release-сборка подписывается локальным ключом `release.jks` — в репозитории он не хранится.

## Приватность

Данные не покидают устройство: без аккаунтов, аналитики и телеметрии. Политика конфиденциальности — `docs/privacy.html`.
