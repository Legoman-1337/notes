# Заметки 3.1

## Изменения

- В Android и Windows добавлена кнопка «Удалить аккаунт»: Настройки → Дополнительно, после входа в аккаунт. В гостевом режиме её нет.
- Действие требует двух подтверждений, включая ввод «УДАЛИТЬ».
- Обрабатываются облачные записи текущего пользователя и связанные вложения; затем аккаунт блокируется и локальные заметки аккаунта очищаются. Это не физическое удаление пользователя Appwrite. Полное удаление файлов не гарантируется при ошибках доступа; функция требует дополнительной доработки для Google Play.
- Версия приложения обновлена до 3.1 (Android versionCode 12).

## Загрузка

- `zametki-3.1.0.apk` — Android 12 и новее. Для совместимого обновления с 3.0 сохранена прежняя отладочная подпись. Не удаляйте приложение перед установкой обновления: удаление приложения может стереть локальные заметки.
- `zametki-windows-portable-3.1.0.zip` — Windows x64, распакуйте весь архив и запустите `UdobnyeZametki.exe`. Среда Java включена.
- `sources-3.1.zip` — снимок исходников, из которых собраны эти файлы; используйте его вместо автоматически созданных GitHub архивов Source code, привязанных к коммиту тега.
- `SHA256SUMS.txt` — контрольные суммы загружаемых файлов.
- `GOOGLE_PLAY.md` — оставшиеся требования для Google Play.

## Статус Google Play

Это выпуск через GitHub, не готовая публикация в Google Play. Требуются API 36, постоянная релизная подпись, полноценное удаление аккаунта, опубликованные политика конфиденциальности и способ запроса удаления данных, заполнение деклараций и проверка на устройствах.

Сборка не заменяет проверку на устройстве. Удаление на настоящем аккаунте Appwrite не тестировалось; данные сервера при подготовке релиза не изменялись.
