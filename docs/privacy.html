Политика конфиденциальности

Приложение «Удобные заметки». Дата обновления: 28 ноября 2026.

Какие данные мы храним

  • Заметки: заголовки, текст, таблицы, разделы, отметки избранного.
  • Вложения: фотографии и файлы, прикреплённые к заметкам.
  • Настройки и данные плагинов: параметры оформления и данные, которые вы сохраняете внутри приложения.

Где хранятся и передаются ли данные

Все заметки, вложения, плагины и настройки хранятся только локально на вашем устройстве. Регистрация и вход в аккаунт не требуются. Мы не собираем, не продаём и не передаём ваши данные третьим лицам или рекламным сервисам. Рекламы и аналитики в приложении нет.

Доступ в интернет используется только для проверки и загрузки обновлений приложения через GitHub Releases, а также при переходе по внешним ссылкам по вашей инициативе.

Разрешения

  • Уведомления — чтобы показывать напоминания к заметкам.
  • Точные будильники — чтобы напоминание сработало в назначенное время.
  • Интернет — для проверки и загрузки обновлений.
  • Вибрация, звук, работа в фоне — для сигнала напоминаний.

Удаление данных

Вы можете удалить любые заметки вручную внутри приложения или создать резервную копию через Настройки → Копии → Экспорт. На Android все локальные данные можно удалить через системные настройки приложения, на Windows — при удалении через «Установленные приложения» с отметкой «Удалить также заметки и настройки».
